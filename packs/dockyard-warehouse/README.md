# Dockyard Warehouse

Starter encounter pack for Marvel Encounter Framework.

## Included
- `encounter.json` — MEF manifest
- `scene.json` — Foundry scene seed from the map pack
- `art/background.png` — realistic background
- `art/foreground.png` — transparent overhead layer
- `regions.json` — semantic Region definitions (starter/empty)
- `objects.json` — environmental objects (starter/empty)
- `objectives.json` — initial objectives
- `phases.json` — initial encounter phases

The Regions and environmental objects are intentionally left light so we can author them against live Foundry v14 behavior after the MEF Region milestone is proven.
